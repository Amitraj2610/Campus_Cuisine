# 🍔 Campus Cushion – Smart Canteen Website

> A responsive smart canteen website designed to make campus food discovery faster, easier, and more convenient.

## 📌 About the Project

Campus Cushion is a smart canteen website developed to simplify the way students and campus users explore canteen items and services.

Traditional canteen processes often require students to visit the counter or manually check available food items. This project aims to solve that problem by providing a simple, responsive, and user-friendly digital platform where users can conveniently explore canteen offerings.

The website improves the food discovery experience and helps users find canteen items up to **2x faster** compared to the manual process.

## 🎯 Problem Statement

Campus users needed a quick and simple way to view canteen items and access canteen services. Traditional manual processes could be time-consuming and inconvenient, especially during busy college hours.

## 💡 Solution

Developed Campus Cushion, a responsive smart canteen website that provides an easy-to-use interface for exploring canteen items and accessing available services.

## ✨ Key Features

- **Responsive Design:** Works across desktops, tablets, and mobile devices.
- **User-Friendly Interface:** Simple and intuitive website navigation.
- **Food Discovery:** Makes it easier for users to explore canteen items.
- **Smart Canteen Experience:** Provides a digital approach to accessing canteen services.
- **Improved Accessibility:** Allows campus users to access canteen information conveniently.
